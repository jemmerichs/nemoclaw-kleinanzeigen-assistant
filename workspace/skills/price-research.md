# Skill: Preisrecherche

Marktpreise für einen Artikel auf Kleinanzeigen recherchieren.

**Wann:** Jannik fragt nach einem Preis, oder während Anzeige-Erstellung.

**Hard skills benötigt:** `searchAds` — noch nicht verfügbar, Claude Code baut dieses.

**Ablauf (sobald Tool verfügbar):**
1. Artikelname erfragen falls nicht gegeben
2. `searchAds` aufrufen — ähnliche Anzeigen suchen
3. Preisspanne und Empfehlung ausgeben

**Bis dahin:** Jannik informieren, manuellen Vergleich auf kleinanzeigen.de empfehlen.
