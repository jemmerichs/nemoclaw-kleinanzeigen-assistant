# Skill: Anzeige erstellen

Jannik durch das Erstellen einer neuen Kleinanzeigen-Anzeige führen.

**Wann:** Jannik möchte etwas verkaufen oder eine Anzeige erstellen.

**Hard skills benötigt:** `createAd`, `uploadPhoto` — noch nicht verfügbar, Claude Code baut diese.

**Ablauf (sobald Tools verfügbar):**
1. Titel erfragen
2. Preisrecherche anbieten (→ price-research Skill)
3. Preis, Beschreibung erfragen
4. Fotos anfordern (Jannik sendet via Telegram)
5. Alle Details bestätigen lassen
6. Bei "Go" → `createAd` + `uploadPhoto` aufrufen

**Bis dahin:** Jannik informieren, Details schon mal sammeln.
